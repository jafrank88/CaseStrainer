# Extension Icons

This extension requires three icon sizes:

- `icon16.png` - 16x16 pixels (toolbar)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Create Icons

You can create icons using the provided `icon-template.svg` or any graphics editor.

### Recommended Design

- **Symbol**: Balance scales (⚖️) or gavel
- **Colors**: Blue (#0d6efd) and white
- **Style**: Simple, clean, recognizable at small sizes

### Convert SVG to PNG

Using Inkscape, GIMP, or online tools:

1. Open `icon-template.svg`
2. Export as PNG:
   - 16x16 pixels → `icon16.png`
   - 48x48 pixels → `icon48.png`
   - 128x128 pixels → `icon128.png`
3. Place PNG files in this directory

### Online Conversion Tools

- https://cloudconvert.com/svg-to-png
- https://svgtopng.com/
- https://image.online-convert.com/convert-to-png

### Temporary Solution

For development/testing, you can use any 16x16, 48x48, and 128x128 PNG images as placeholders.
